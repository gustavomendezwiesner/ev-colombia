# UX / DESIGN PRINCIPLES

## Objetivo

No crear un dashboard corporativo.

Crear una experiencia digital que una persona quiera explorar.

## Principios

- Mobile first
- Visual
- Rápida
- Interactiva
- Datos fáciles de entender
- Progressive disclosure
- Una acción principal por pantalla
- Poco texto
- Grandes tarjetas
- Mapas visuales
- Scores
- Rankings
- Comparaciones

## Experiencias principales

### Home

Pregunta principal:

¿Estás listo para conducir eléctrico en Colombia?

### Mapa

Mapa + filtros + estaciones + estado.

### Estación

Mostrar primero:

- disponibilidad
- potencia
- conector
- distancia
- precio

Después información secundaria.

### Ruta

Origen → destino → vehículo → paradas → autonomía → costo.

### Ranking

Ciudades / rutas / estaciones.
